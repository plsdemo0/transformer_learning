# Дорожная карта проекта

> Пошаговое изучение архитектуры трансформеров через реализацию в Jupyter Notebook с PyTorch

## Вехи

- [x] **Настройка окружения** — установка PyTorch, создание базового ноутбука, проверка GPU (CUDA/MPS), структура проекта для экспериментов

- [x] **Основы тензоров и автограда** — знакомство с тензорами PyTorch, операциями, механизмом автоматического дифференцирования — фундамент для нейронных сетей

- [x] **Линейные слои и нелинейности** — реализация полносвязных слоёв, функции активации (ReLU, GELU), построение простейшего классификатора, визуализация градиентов

- [ ] **Внимание (Attention) с нуля** — реализация механизма Scaled Dot-Product Attention, демонстрация работы Q, K, V, визуализация карт внимания на синтетических данных

- [ ] **Multi-Head Attention** — расширение одно-голового внимания до多头, реализация конкатенации голов и проекционного слоя, анализ влияния числа голов

- [ ] **Позиционные кодирования** — реализация синусоидальных позиционных кодировок (Vaswani et al.), изучение обучаемых позиционных эмбеддингов, визуализация паттернов

- [ ] **Transformer Encoder** — сборка энкодерного блока: Multi-Head Attention + Add&Norm + Feed-Forward + Add&Norm, реализация остаточных связей и LayerNorm

- [ ] **Transformer Decoder** — реализация декодерного блока: Masked Self-Attention, Cross-Attention (запросы от декодера, ключи/значения от энкодера), каузальная маскировка

- [ ] **Полный Transformer (Encoder-Decoder)** — сборка полной архитектуры seq2seq, демонстрация на задаче перевода или копирования последовательностей

- [ ] **Обучение трансформера** — реализация цикла обучения, функции потерь (CrossEntropy), планировщика learning rate (Noam scheduler), мониторинг сходимости

- [ ] **BERT: Masked Language Modelling** — реализация BERT-подобной модели (только энкодер), задача MLM (маскирование токенов), анализ контекстуальных представлений

- [ ] **GPT: Causal Language Modelling** — реализация GPT-подобной модели (только декодер), авторегрессивная генерация, техники сэмплирования (top-k, top-p, temperature)

- [ ] **Визуализация внимания** — извлечение и построение карт внимания, анализ паттернов на разных слоях/головах, сравнение энкодера и декодера

- [ ] **Знакомство с HuggingFace Transformers** — загрузка предобученных моделей (BERT, GPT-2), дообучение (fine-tuning) на кастомном датасете, сравнение с реализацией "с нуля"

- [ ] **Финальный ноутбук: сквозной пример** — объединение всех концепций в один читаемый ноутбук, классификация текста трансформером с нуля, сравнение с предобученной моделью
