# Ashat_AI — Описание проекта

## Обзор
Проект "Ashat_AI" (от каз. "ас" — еда) — скелет Python-проекта для анализа данных в области food-tech / пищевой промышленности. На данный момент не содержит исходного кода, только настроенную инфраструктуру.

## Основные компоненты
- **data/** — каталог для наборов данных
- **models/** — каталог для сериализованных моделей
- **sample.ipynb** — заготовка Jupyter Notebook

## Технологический стек
- **Язык:** Python 3.9.6
- **Библиотеки:** numpy, pandas, matplotlib, jupyterlab, ipykernel, torch, torchvision, torchtext, transformers, datasets
- **Виртуальное окружение:** .venv/

## Архитектурные заметки
- Проект находится на стадии скелета — кодовая база отсутствует
- Предполагается разработка в Jupyter Notebook с последующим переносом в .py-модули
- Модели будут сохраняться в `models/`, данные — в `data/`
- Зависимости добавляются в `requirements.txt`

## Требования
- Настройка логирования через переменные окружения
- Обработка ошибок с явным логированием
