# Базовые правила проекта

> Автоматически определённые соглашения из анализа кодовой базы. Отредактируйте при необходимости.

## Соглашения об именовании

- Файлы: `snake_case.py`
- Переменные: `snake_case`
- Функции: `snake_case`
- Классы: `PascalCase`

## Структура модулей

- Модули уровня проекта (.py) — в корне репозитория до появления пакетной структуры
- Ноутбуки — в `data/` или корне

## Обработка ошибок

- Использовать try/except с логированием

## Логирование

- Настраиваемый уровень через LOG_LEVEL
- Писать логи в stderr
